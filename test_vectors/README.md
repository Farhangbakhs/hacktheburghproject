# Golden test vectors

Generated by Person 2 from the bit-exact Python models in `sw/reference/`. They're deterministic, so regenerating gives identical files.

| Folder | Contract | Generator | Use |
|---|---|---|---|
| `v2_saracen/` | **Proposed section 3 v2**: saracen Laplacian EVM, int16 Q8.8 band words, 25,200 per frame | `gen_vectors_saracen.py` | **current target** |
| `v2_saracen/edge/` | same, extreme registers, mid-stream INIT | | |
| `v1_contract/` | Original PLAN.md section 3: 160x120 BGR uint8 in, int8 out | `gen_vectors.py` | fallback |
| `v1_contract/edge/` | same, extreme registers, mid-stream INIT | | |

Each folder contains:
- the input stream (`input_words.bin` or `input_frames.bin`),
- `expected_output.bin`,
- `expected_state.bin`: filter state after the first frames, for debugging,
- `params.json`: registers, sizes, `init_frames`, byte layout and sha256.

Why we moved to v2, plus the kernel spec, register table, HLS sketch and verify commands: **`sw/reference/HANDOFF_JACK.md`**.

```
cd sw/reference
.venv\Scripts\python gen_vectors_saracen.py verify --got <kernel_output.bin>
```
